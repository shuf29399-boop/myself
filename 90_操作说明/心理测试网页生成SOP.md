# 心理测试网页生成 SOP

## 目标

用户只要给一个心理测试主题，就自动生成一套可发布的小红书引流心理测试网页，并配套完整文案资料。

核心原则：

```text
网页负责上线，Markdown 文本包负责沉淀内容。
```

## 一、输入主题

用户输入一个测试标题，例如：

```text
你适合继续考研，还是先去上班？
```

AI 需要先判断主题类型：

- 情感关系类：用柔和粉色、奶油色、女性化视觉。
- 职业选择类：用奶油色、灰绿色、中性色。
- 赚钱副业类：用清爽、信任感、轻商业风。
- 自我成长类：用温和、治愈、探索感视觉。

## 二、生成测试内容

每个测试至少包含：

- 1 个测试标题
- 1 个副标题
- 1 段开篇文案
- 4 个测试维度
- 30 道测试题
- 每道题 4 个选项 A/B/C/D
- 4 种结果类型
- 每个结果一份完整报告

注意：

- 30 道题的选项不能全部一样。
- 每道题的选项要贴合题目。
- 结果不能像算命，要像“自我探索报告”。
- 城市类结果统一使用“城市适配分析”等中性标题，不使用“为什么某城市适合你”这类替用户下结论的句式。
- 文案要适合小红书女性用户。
- 不要写得太硬、太学术。

## 三、测试网页结构

### 1. 首页

展示：

- 测试标题
- 副标题
- 开篇说明
- 测试维度
- 开始按钮

### 2. 答题页

展示方式：

- 一次展示一道题。
- 用户选择 A/B/C/D 后进入下一题。
- 显示当前进度。

### 3. 计算逻辑

每个选项对应一种倾向：

```text
A = 结果类型 A
B = 结果类型 B
C = 结果类型 C
D = 结果类型 D
```

最后统计 A/B/C/D 哪个最多，生成对应结果。

### 4. 结果页

展示：

- 结果名称
- 指数分数
- 核心结论
- 截图金句
- 完整报告演示版
- 未来 7 天建议

## 四、结果报告格式

每个结果建议包含：

```text
结果名称：
指数名称：
基础分数：
一句话总结：
核心结论：
截图金句：
隐藏优势：
主要卡点：
适合路径：
未来 7 天建议：
```

示例：

```text
结果名称：考研深造型
指数名称：深造适配指数
基础分数：88
一句话总结：你不是盲目逃避就业，而是确实更适合用一段系统学习，换取更高的平台和专业门槛。
核心结论：你适合继续考研，不是因为上班不好，而是你的目标更需要平台、学历或系统训练来打开下一层空间。
截图金句：不是所有上岸都叫正确，但你的上岸需要有清晰目的。
隐藏优势：你能在长期准备中积累竞争力，适合系统学习和专业深耕。
主要卡点：容易把考研当成唯一答案，忽略院校、专业和就业回报是否匹配。
适合路径：先定目标行业，再反推是否必须读研，而不是先考试再想未来。
未来 7 天建议：完成目标院校、专业难度、就业去向和 90 天复习节奏表。
```

## 五、视觉风格

### 情感类

适合主题：

- 恋爱
- 暧昧
- 关系
- 喜欢
- 安全感
- 恋爱脑

视觉建议：

- 背景：粉白、奶油、浅玫瑰。
- 按钮：玫瑰粉、珊瑚色。
- 卡片：圆角、柔和阴影。
- 语气：温柔、细腻、共情。

### 职业 / 人生类

适合主题：

- 考研还是上班
- 城市选择
- 职业方向
- 躺平还是内卷
- 换工作还是继续坚持

视觉建议：

- 背景：奶油白、灰绿、浅米色。
- 按钮：灰绿、深橄榄色。
- 卡片：简洁、清爽。
- 语气：清醒、稳定、陪伴感。

### 赚钱 / 副业类

适合主题：

- 适合靠什么赚钱
- 副业方向
- 变现能力
- 个人优势

视觉建议：

- 背景：浅奶油、淡金、浅绿。
- 按钮：暖橙、金棕、灰绿。
- 卡片：干净、有信任感。
- 语气：轻商业、清晰、有行动感。

### 避免

- 黑白网格
- 太男性化
- 太像考试系统
- 太多说明文字
- 太复杂的交互
- 太像医院心理测评

## 七、小红书配套内容

每个测试都要生成小红书素材：

- 5-10 个爆款标题
- 封面文字
- 轮播图文案
- 正文
- 置顶评论
- 评论区回复模板
- 标签

### 小红书引导方式

```text
想测的姐妹，评论区发“关键词”，我发你入口。
```

### 标题风格

常用标题结构：

```text
你适合 A，还是 B？
测一测，你现在更适合哪条路
你的 XX 程度到了第几级？
真正适合你的人生方向，其实早有信号
你不是没答案，只是没看清自己的类型
```

### 评论区回复模板

```text
想测的姐妹，评论区发“测试”，我发你入口。
```

```text
你这个结果其实很典型，不是你不努力，而是你现在更需要换一种路径。
```

```text
如果你测出来是这个类型，建议重点看报告里的“主要卡点”和“未来 7 天建议”。
```

## 八、发布方式

网页生成后，发布到 GitHub Pages。

固定结构：

```text
tests/测试slug/index.html
tests/测试slug/test_config.json
```

链接格式：

```text
https://用户名.github.io/仓库名/tests/测试slug/index.html
```

首页链接：

```text
https://用户名.github.io/仓库名/
```

当前示例：

```text
https://shuf29399-boop.github.io/myself/tests/exam-or-work/index.html
```

## 九、长期规则

以后用户说：

```text
心理测试 + 主题
```

AI 就应该自动完成：

1. 生成 30 道题
2. 生成 4 个结果
3. 生成完整报告
4. 生成网页
5. 生成小红书文案
6. 生成完整文本包
7. 本地检查是否可打开
8. 用户明确说“保存/发布”后，再上传 GitHub

## 十、保存规则

默认只生成和整理本地内容。

只有用户明确说：

```text
保存
提交
上传
发布
```

才执行 git commit、git push 或 GitHub Pages 发布动作。
