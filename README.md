# 心理测试

这个文件夹用来管理心理测试项目：对标拆解、完整文本包、网页生成、GitHub 发布和小红书素材。

## 常用入口

2. [[01_测试完整文本库/README|01 测试完整文本库]]
3. [[02_小红书发布素材_已合并到完整文本库/README|02 小红书发布素材]]
4. [[90_操作说明/README|90 操作说明]]
5. [[90_操作说明/心理测试自动化使用说明|心理测试自动化使用说明]]

## 最新工作方式

以后每一个心理测试都尽量整理成一个完整文本包，放在：

`01_测试完整文本库`

每个完整文本包包含：

- 测试基础信息
- 公开链接和本地页面
- 开篇文案
- 测试维度
- 30 道题和所有选项
- 基础结果
- 完整报告演示版
- 小红书发布素材
- 后续优化记录

## 本地文件夹分工

- `00_对标内容`：橘猫账号商业模式、心理测试复刻方案、界面参考拆解。
- `01_测试完整文本库`：每一个测试一份完整 Markdown，是以后查看和修改的主入口。
- `02_小红书发布素材_已合并到完整文本库`：早期单独生成的小红书文案备份，现在优先看完整文本库。
- `小红书封面`：封面图素材。
- `tests`：GitHub Pages 线上正式访问的网页文件，不要手动乱改。
- `site`：发布前的网页汇总目录。
- `output`：生成器输出目录。
- `90_操作说明`：GitHub、发布、自动化说明。
- `skills`：自动化规则。

以后你只需要给一个主题，比如：

- 你适合稳定上班，还是自由赚钱？
- 你在关系里，到底需要哪种爱？
- 你最近的焦虑，到底在提醒你什么？

我就可以帮你生成：

- 测试标题
- 30 道题
- 4 个结果类型
- 完整报告演示版
- 小红书发布素材
- 一个完整文本包
- 一个可以直接打开和发布的网页

## 使用方法

在这个文件夹里运行：

```bash
python3 generate_test.py "你适合稳定上班，还是自由赚钱？"
```

生成后的网页会出现在：

```text
output/你的测试主题/index.html
```

双击 `index.html` 就可以在浏览器里打开。

## 上线说明

现在这个版本已经能生成静态网页。

要自动部署成公网链接，需要再接入一个部署平台：

- GitHub Pages
- Cloudflare Pages
- Netlify
- Vercel

接入后，流程可以变成：

`输入主题 → 自动生成网页 → 自动上传部署 → 返回可访问链接`
